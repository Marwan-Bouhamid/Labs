# Lab Stack — Explorer les technologies de mon projet

Ce lab aide à comprendre comment les différents outils d’un projet web se complètent. L’exemple fil rouge est mon application de **gestion des entraînements et des groupes musculaires**.

## Ce que je vais apprendre

- Expliquer le rôle d’un lab dans un parcours de développement.
- Repérer les technologies utilisées dans mon projet.
- Décrire comment l’interface, le serveur et la base de données échangent des informations.
- Relier les exercices pratiques aux besoins de l’application.

## Avant de commencer

Il est utile de connaître les bases du développement web et d’être à l’aise avec les notions de fichiers, de navigateur et de terminal. Aucune expertise avancée n’est nécessaire : le lab est conçu pour progresser étape par étape.

## Parcours du lab

### 1. Comprendre l’approche par labs — 20 min

Un lab est une activité courte qui permet d’explorer un sujet précis dans un cadre limité. On peut y essayer une technique, observer son résultat et noter ce qu’on a appris avant de l’utiliser dans une fonctionnalité plus complète.

Cette méthode permet de :

- avancer sur un sujet à la fois ;
- repérer les difficultés tôt ;
- garder une trace des essais et des décisions ;
- réutiliser les apprentissages dans le projet principal.

Dans mon projet, un lab peut par exemple servir à tester l’affichage d’une liste d’entraînements ou l’enregistrement d’un groupe musculaire avant de relier toutes les pages.

### 2. Repérer les composants de la stack — 30 min

La stack de mon application réunit plusieurs technologies, chacune avec une responsabilité particulière :

| Partie | Technologie | Utilisation |
|:-------|:------------|:------------|
| Serveur | PHP | Traiter les requêtes et préparer les réponses |
| Données | MySQL et PDO | Stocker et consulter les informations |
| Structure des pages | HTML | Organiser les contenus de l’interface |
| Présentation | CSS et Tailwind CSS | Mettre en forme les pages et composants |
| Interactions | JavaScript | Ajouter des comportements dans le navigateur |

L’ensemble permet de gérer les entraînements et leurs liens avec les coachs et les groupes musculaires.

### 3. Situer les labs dans le parcours — 10 min

Les thèmes ci-dessous couvrent les outils, les méthodes et les notions utiles au projet. Ils sont organisés par grandes étapes d’apprentissage.

#### Fondations et outils

Markdown, GitHub Pages, Antigravity, Marp, OpenCode, Pandoc, OmniRoute, Tailwind CSS et Preline.

#### Méthodes et collaboration

2TUP, Design Thinking, issues GitHub, Scrum, Copilot GitHub et diagrammes ASCII.

#### Développement et langages

Programmation orientée objet, PHP natif, Laravel, Kotlin, JavaScript moderne, gestion des erreurs JavaScript, prompts et agents IA.

#### Projet et mise en pratique

Veille technologique, templates de démarrage, planification, Git, découverte de la stack et agents IA.

## À réaliser

- [ ] Présenter les technologies utilisées dans l’application.
- [ ] Expliquer le rôle de chaque partie de la stack.
- [ ] Illustrer le parcours des données entre une page, PHP et MySQL.
- [ ] Préparer un schéma simple de l’architecture.
- [ ] Présenter les apprentissages à la fin du lab.
