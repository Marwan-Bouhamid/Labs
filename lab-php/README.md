# lab-php

## Objective
This lab allows you to study and put into practice three advanced PHP concepts:

- **Error and Exception Handling**: Detect and handle abnormal situations (try/catch, Throwables, custom exceptions).
- **Namespaces**: Organize code, structure directories, and avoid class name conflicts.
- **Traits**: Reuse code across multiple classes without multiple inheritance (horizontal composition).

For each concept, explain its role and implement a practical example related to the project architecture.

## Assigned Work
1. Research the three concepts and explain their core principles.
2. Implement a practical example for each inside the `pratique/` folder or associated files.
3. Verify the examples and explain their integration into the architecture.
4. Structure the presentation in `presentation.md` in Marp format.
